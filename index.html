ResNet-101 Layer-by-Layer Architectural Pipeline

Understanding how 101 deep residual layers extract spatial features without gradient degradation

Stage 1

Conv1 + MaxPool

7×7 kernel, stride 2, 64 channels followed by 3×3 max pooling. Resolves low-level edge and color contrast gradients.

Output: 112×112×64
Stage 2

ResBlock Conv2_x

3 residual bottleneck blocks with 1×1, 3×3, 1×1 convolutions. Identifies basic textures and primitive contours.

Output: 56×56×256
Stage 3

ResBlock Conv3_x

4 residual bottleneck blocks. Detects structural geometric shapes, repeating patterns, and object boundary contours.

Output: 28×28×512
Stage 4

ResBlock Conv4_x

23 residual bottleneck blocks (the deep core). Synthesizes complex semantic components like eyes, wheels, and wings.

Output: 14×14×1024
Stage 5

ResBlock Conv5_x + FC

3 residual blocks + Global Average Pooling (GAP) collapsing spatial dimensions to 2,048-dim vector into 1,000 Softmax classes.

Output: 1,000 Classes
